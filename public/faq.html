Preguntas frecuentes

Respuestas rápidas sobre inspección, captura, informe y certificado.

¿Qué es Ainspecciona?

Es un sistema de inspección técnica digital que analiza propiedades a partir de fotografías guiadas y genera un informe técnico estructurado con evaluación objetiva y certificado publicable.

¿Quién puede solicitar una inspección?
  • Corredores de propiedades
  • Oficinas inmobiliarias
  • Administradores
  • Propietarios
  • Inversionistas
¿Cómo se realiza la inspección?
  1. Se compra el crédito.
  2. Se completa el formulario del inmueble.
  3. Se envía por mail el link de captura.
  4. Se toman las fotos siguiendo el proceso guiado.
  5. Se emite el informe técnico y el certificado.
¿Cuánto demora el informe?

El análisis se envía en 24 horas una vez finalizada la carga fotográfica.

¿Qué incluye el informe?
  • Evaluación por áreas (KPI técnicos)
  • Observaciones detectadas
  • Evidencia fotográfica
  • Diagnóstico estructurado
  • Certificado con score publicable
¿El certificado se puede publicar?

Sí. Puede usarse como última imagen del aviso o incluir el QR para acceder al informe completo.

¿Necesito aplicación?

No necesariamente. Funciona mediante enlace web. Puedes agregar la página a la pantalla de inicio como acceso directo.

¿Es reemplazo de una inspección presencial?

No. Es un diagnóstico técnico estandarizado basado en evidencia fotográfica. Sirve como filtro, respaldo comercial y elemento diferenciador.

¿Qué pasa si la propiedad tiene fallas graves?

El sistema las detecta y clasifica. En ese caso se recomienda una inspección técnica presencial que puedes contratar en nuestra página.

¿Puedo hacer varias inspecciones?

Sí. Cada inspección funciona por crédito individual o bolsa según el plan contratado.

¿Qué es un slot técnico?

Un slot es un componente específico del inmueble (ej.: ducha, muro, tablero) con instrucciones de captura y análisis propio.

¿Cómo se genera el badge final?

Se consolida la severidad y confianza de los slots y KPIs para definir un estado claro: verde, amarillo o rojo.

¿Qué pasa si una foto no es válida?

La captura se valida por calidad y se puede pedir reintento para asegurar evidencia útil.
